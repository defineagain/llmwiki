# RAG

Stub — created to satisfy a `[[wikilink]]` from the seed pages.

Retrieval-augmented generation. The standard pattern: chunk source
documents, embed each chunk, store in a vector index, retrieve by
similarity to the query, prepend the chunks to the prompt.

Contrast with [[pre-compiled-rag]], which bakes structure into pages
at write time rather than recovering it at query time.
